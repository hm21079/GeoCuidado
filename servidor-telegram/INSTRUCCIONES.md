GEOCUIDADO TELEGRAM - INSTRUCCIONES

1. Completa servidor-telegram/.env con tus credenciales privadas de Firebase y Telegram.
2. En terminal: cd servidor-telegram && npm install
3. Prueba: npm run test:telegram
4. Inicia: npm start (deja la terminal abierta).
5. En la web, registra un responsable, pulsa Vincular Telegram y comparte su enlace individual.
6. El responsable pulsa Iniciar en el bot. El servidor debe estar funcionando para procesar el vínculo.
7. Programa los cuidados; se enviarán en la hora de El Salvador con el servidor activo.

El servidor guarda vínculos en .estado-local.json: NO borres ese archivo después de vincular.
Los chats configurados en .env también reciben alertas; déjalos vacíos si quieres SOLO responsables vinculados.
El primer arranque ignora avisos antiguos. No es un servicio de emergencias garantizado.
